# 小猫重置雷达 · 0.1.0

A read-only, Cloudflare-backed Codex reset panel. No API key or AI conversation is needed.

安装、通知方式与客户端兼容范围：https://codex-reset-radar.weican16hit.workers.dev/install

面板：https://codex-reset-radar.weican16hit.workers.dev/

远程 MCP：https://codex-reset-radar.weican16hit.workers.dev/mcp （无需认证）

在支持 MCP App 静态入口的客户端，点击应用入口打开。CLI 不渲染 UI。新事件提示和声音仅在面板打开时工作；后台提醒通过网站现有通知渠道。没有个人额度读取、系统后台推送或自动开工。

独立社区项目，由 farmcan 维护，与 OpenAI 无官方隶属关系。MIT。
