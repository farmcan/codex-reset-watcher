把小猫带到另一台电脑。

v0.1.0 预览版 · 无需 API Key

所有电脑读取同一份 Cloudflare 公开结果。无需配置 X API，也不需要提供 OpenAI API Key。面板不会发起模型对话。

同一账号，直接打开个人测试插件

已经在本次使用的 ChatGPT 账号中创建并连接了个人云端插件。在另一台电脑登录同一账号，可先试这个入口：

打开个人测试插件 →

已在真实 ChatGPT Web 宿主内验证：直接打开、读取动态及刷新，不发送聊天消息。Codex 原生窗口的入口仍待实测。此链接只面向已连接的当前账号，不代表其他账号已获访问权限；其他账号可采用下面的仓库或自定义 MCP 接入。

通过仓库安装 Codex 插件

在装有新版 Codex CLI 的电脑终端运行：

codex plugin marketplace add farmcan/codex-reset-watcher --ref plugin-v0.1.0
codex plugin add reset-radar@reset-radar

安装后重新打开客户端或开始新会话，让插件配置生效。在支持 MCP App 静态入口的客户端，从插件应用入口打开「小猫重置雷达」。CLI 本身没有图形面板。

此版本通过 GitHub 仓库分发，尚未进入官方公共插件目录。当前 Codex 图形入口仍待宿主实际验收；插件被安装或 MCP 连接成功，不等于该客户端一定显示静态面板。

通过远程 MCP 连接

在支持自定义 MCP 与 MCP App 界面的客户端中，添加以下地址，认证选择「无」。这是备用接入方式，具体功能取决于客户端。

https://codex-reset-radar.weican16hit.workers.dev/mcp

官方公共目录发布需要开发者身份认证、域名验证和审核；仓库测试分发不要求先通过公共目录审核。查看官方发布流程 ↗

查看与通知

  • 面板打开时每分钟刷新，关闭后停止轮询；来源仍按云端原有频率检查。
  • 有新事件时显示面板内提示，可主动开启提示音。
  • 离开面板后的提醒，请通过「选择通知渠道」进入网站，加入既有通知渠道。
  • 当前不提供插件后台系统推送，也不会自动开工。
