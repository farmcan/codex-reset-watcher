15 entries · ideas / bounties / OSS / quality · expandCollapse

Have quota left before a reset? Spend it on patches, measured improvements, bug reproductions or source-backed notes. Choose an output, then a tool.

Upstream docs and selected source reviewed · 2026-10-22

Pick one useful job
  • 20–40 minutes: fix one to three reproducible issues and leave regression tests.
  • 30–60 minutes: optimize one fixed benchmark and preserve the experiment log.
  • No coding task: turn a few existing sources into traceable knowledge cards.

Claim a funded issue

Opire · earn a bounty ↗

Task prompt
Shortlist three open, reproducible bounties. Check reward, acceptance criteria, competing PRs, maintainer activity and AI policy. Do not claim or submit automatically; after selection, complete one small patch.

Contribute to a dependency you use

Send a real fix upstream ↗

Start with a bug you actually encounter in a library or tool you use; a real reproduction gives the contribution a clear purpose.

Output: A minimal reproduction, regression test, compatibility notes and PR draft.

Task prompt
Pick one observed bug in a dependency of this project. Check existing issues and PRs, reproduce it, follow the contribution guide and verify the smallest fix. Deliver a reviewable PR draft without unrelated refactors.

Ordinary contributions usually have no reward and maintainers decide whether to merge. Check the license, CLA/DCO and AI policy before submission.
