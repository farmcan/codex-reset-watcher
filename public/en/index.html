Scope

This project tracks public, provider-wide reset signals. It does not read your personal five-hour or weekly window and does not predict your private reset time. Only a clear first-party future hard reset can produce a “bring forward existing work” note; community rumors never become usage instructions.

Open source, unofficial, and unaffiliated with OpenAI, X, or any monitored account. The logo is an original project SVG.
