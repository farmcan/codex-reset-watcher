# Codex 重置雷达

**看重置、收提醒、找任务。**

**介绍**：整理 Codex 的公开重置动态，区分预告与完成确认。有新消息可收钉钉提醒，也提供值得投入剩余额度的任务 Ideas。

**实现方案**：Cloudflare 定时获取公开信息，规则与 AI 复核消息含义，D1 保存原文、引用关系和投递记录，再同步到网页、RSS 与钉钉。

**关键亮点**：沿真实引用关系串起预告和后续确认；时间和原帖可追溯；通知去重并保留异常记录；开源、可自托管。

**价值**：减少反复查消息和临时找任务的负担，把可用额度用在代码、调研、开源贡献等能验收的产物上。
