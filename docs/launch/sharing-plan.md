## 技术社区帖

### 标题

开源 Codex 重置雷达：看公开证据、收钉钉提醒、找值得做的任务

### 正文

用 Codex 时，我经常遇到两个问题：看到“要重置了”，却不清楚是预告、已经完成，还是一张可保存的 reset 卡；还有额度时，又临时想不到值得交给它做什么。

所以做了 **Codex 重置雷达**：把公开动态、原帖和后续确认放在一起，有新消息收钉钉提醒，再从任务 Ideas 中挑一件能留下产物的事。

目前能用的部分：

- 区分重置预告、完成确认、banked reset 与弱暗示，保留原帖和时间线；没有精确执行时刻就标未公布。
- 钉钉云端 DING 已做实发与去重验收，当前向配置的接收者投递；接收范围以站内说明为准。
- 网页、RSS 与抓取 / 复核 / 投递状态可查；Ideas 附任务模板、预期产物和时间上限，供自己选择执行。

实现用 Cloudflare Workers + D1，持续追踪已启用的一手公开来源，结合规则与 AI 复核引用上下文。公开数据进入网页和 RSS，通知进入持久队列，保留投递结果。代码 MIT 开源，可自托管。

同类工具已经不少：[CodexBar](https://github.com/steipete/CodexBar) 适合查看个人用量，[Reset Watch](https://resetwatch.app/) 提供公开公告和 RSS / 日历，[LimitTracker](https://limittracker.com/)、[CodeReset](https://codereset.dev/) 也有手工倒计时。我把重点放在公开消息的证据链、钉钉提醒，以及接下来能做什么。

公开公告不代表你的账号已经到账，个人余额请核对 Codex Usage。本站没有自动读取个人额度，不做精准重置预测；Dot 自动开工目前未启用。

体验：[Codex 重置雷达](https://codex-reset-watcher.weican16hit.workers.dev/)

源码：[farmcan/codex-reset-watcher](https://github.com/farmcan/codex-reset-watcher)

欢迎试用，也想听听：看到一条重置消息时，你最希望先核对哪项信息？
