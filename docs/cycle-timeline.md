# 重置周期时间轴

2026-10-31 实现于现有中英文首页 `#cycles`，置于首屏判断之后。横轴使用北京时间，纵轴每轮重置或独立观察一行；拖动平移，Ctrl+滚轮/按钮/触摸缩放，展开过程节点，点击查看来源。范围超过45天自动合并为月条，点击月份返回逐轮视图。

月统计分开列收录轮次、原帖更新数、官方完成确认、直接到账观察；按照预告开始月份归组，并按原帖与回复链去重。这不是完整平台发放普查。预告、监测收到、首次通知报出、官方确认各有独立时间；实际时间缺失不使用消息发布时间替代。

到账观察通过独立、持久的账本补充。`GET /api/arrival-observations`只公开固定脱敏字段；`POST /api/admin/arrival-observations`使用专用`PERSONAL_OBSERVATION_TOKEN`，只接受已校验的小批量记录，幂等写入现有D1 `app_state`。没有数据库迁移。未知字段（含账号、比例、余额）一律拒绝；手动用卡、正常周补充不得挂到公开轮次上。私人令牌与原始证据不在Git内。

本机监测保存新观察后自动调用这个接口，前端每分钟增量读取。只有明确源post ID才能挂到同一轮；唯一活动轮次的时间匹配属于推断，仍不宣称全局因果。没有归属的观察独立呈现。私聊通知与公共观察写入分别保存结果，不用一条成功回执替代另一条。

首批补录11条脱敏历史记录：9条本机旧额度观察（账号归属未独立核实），2条Usage重置卡获得/使用记录。只有两条历史观察能与公开轮次做唯一时间匹配，保留较弱证据等级，不计入已验证到账。既有公开历史中的社区到账反馈也保持社区等级。导入不会触发旧公告通知。

## 复用与运行条件

选择 [vis-timeline](https://github.com/visjs/vis-timeline) 8.5.6，MIT（从其Apache-2.0 OR MIT双许可中选择），复用分组、范围条、缩放、平移与时间轴；月度聚合和证据口径由本站小型适配层提供。与Frappe Gantt对比后，选择它是因为这里是只读事件范围与观察节点，而非可拖动改期的项目排程。

版本固定在package-lock；浏览器文件自托管于`public/vendor/vis-timeline`，保留许可证和包内版权声明，不依赖外部CDN，不上传个人额度。运行`node scripts/sync-timeline-vendor.mjs`可从锁定依赖重建。2026-10-31 npm审计的8项告警均来自既有Wrangler/Vitest开发工具链，未指向新增vis-timeline依赖；未为此变更擅自升级无关工具。

验证包含：官方完成不等于到账、无引用不就近闭环、重置卡与全量重置分开、历史归属未核不升级、回复链去重、北京时间跨月、完整自然月、隐私字段拒绝、时间区间与普通补充校验；浏览器验证逐轮、月聚合、展开节点、月份跳转、中英文和手机宽度。

真实账号额度变化与下次自然通知尚需事件发生后验收；已有手工采样、私聊测试与历史导入不能替代这一步。个人采样依赖Mac在线与登录，公共Worker不会宣称能证明任意访客本人到账。
